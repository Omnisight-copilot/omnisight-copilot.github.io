# OMNISIGHT — AI Smart Glasses Copilot

**Privacy-conscious, real-time AI copilot for smart glasses.**

OMNISIGHT listens only with consent, understands explicitly selected screen or camera imagery, combines those signals with authorized knowledge, and offers short, discreet answers in a smart-glasses heads-up display (HUD).

- **Meeting Copilot** — Should I speak? · What do I say? · Smart questions · Catch me up · Decisions, risks and actions
- **Visual Copilot** — on-demand camera and screen understanding, OCR, recall of approved notes and docs
- **Hardware-agnostic** — a developer-controlled software layer for RayNeo, Brilliant Labs, XREAL, Even, Vuzix, Mentra and others

**Status:** Working blueprint, November 14, 2026 — not a shipped product. Hardware and API feasibility are being validated with prototypes.
